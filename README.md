# FindMyPG – PG Accommodation System

## About the Project

Finding a suitable Paying Guest (PG) accommodation can be difficult, especially for students and working professionals moving to a new place. FindMyPG is a web-based project designed to make this process easier by bringing PG searching, booking, and management features together in one place.

## Features

- **User Module:** Register, log in, search for PGs, view accommodation details, and manage bookings.
- **PG Owner Module:** Add and manage PG listings and view booking information.
- **Admin Module:** Manage PG information, bookings, messages, and complaints.
- **Booking and Payment:** View booking details and access payment-related pages.
- **Responsive Interface:** Simple web pages designed to make navigation easier.

## Technologies Used

- HTML
- CSS
- JavaScript
- Bootstrap 5

## Data Storage

The project uses browser `localStorage` to store application data. This is browser-based storage, not a shared server database such as MySQL.

## Project Structure

The project contains separate HTML pages for the home page, login and registration, PG search, accommodation details, bookings, payments, and user, owner, and admin dashboards.

## Getting Started

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension to run the pages locally.

## Project Goal

The goal of FindMyPG is to provide a convenient place for users to explore PG accommodations and for owners to manage their listings.
